# 固件改动说明（本地分支相对上游）

底盘固件上游为 `czu963889306-dev/leap_ros_mcu_driver`。本仓库 `firmware/chassis/`
收录的是「上游 main + 本地改动」的快照，并按公开仓库要求做了两项处理：

1. 删除 micro-ROS 组件的 `build/`、`install/`、`log/` 产物与预编译 `libmicroros.a`
   （约 340 MB），改由 ESP-IDF 首次构建时依据 `micro_ros_src/` 源码重新生成。
2. 默认 Wi-Fi 凭据置空（`main/config/network_config.h` 的 `kDefaultStaSsid` /
   `kDefaultStaPassword`），改由设备配网页写入，避免真实口令进入公共仓库。

## 本地相对上游的功能改动

| 改动 | 位置 | 目的 |
| --- | --- | --- |
| micro-ROS 运行时重构（会话重建、订阅/定时器 spin 拆分、紧急停止订阅） | `main/tasks/network/microros/` | 链路断开后可自恢复；急停走独立订阅通道 |
| `time_increment` 按 `scan_time` 计算（先赋值 `scan_time` 再赋值 `time_increment`） | `main/tasks/network/microros/` | 与 GMapping 的时间戳语义对齐，避免雷达时间增量为 0 |
| UART micro-ROS 启动延时（让 Wi-Fi/IP 日志先输出再切换串口波特率） | `main/tasks/network/microros/microros_runtime.cpp` | 避免启动日志与 XRCE-DDS 传输抢 UART0 |
| 统一运动安全：急停、授权与来源仲裁 | `main/control/motion_safety.h`、`main/tasks/network/microros/microros_subscribers.cpp` | 多来源（网页/手柄/上层）同时下发速度时只认一个权威来源 |
| 速度通道隔离、导航目标 UUID 持久账本 | 主机端 `scripts/navigation_bridge.py`（配套） | 速度指令防串号；导航目标可追溯 |

大版本前的固件包（候选/回滚）保存在本地，不入库；需要时按 Release 附件方式单独提供。

## 已知限制

- 预编译 `libmicroros.a` 的发布者槽位（5 个）少于源码注册数（6 个），
  因此 `/wifi_config` 等个别订阅在预编译库下初始化会失败。
  本仓库改为由源码重新编译 micro-ROS，可避开该限制；若改用预编译库需额外处理。
- 硬件相关的默认值（轨道宽度、雷达波特率、GPIO）以 `main/config/` 为准，改车后需同步修改。
