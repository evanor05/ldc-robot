# 迁移过程说明（Humble → Lyrical）

本文汇总迁移基线的审计记录。源环境为 Ubuntu 22.04.5 / ROS 2 Humble（VMware），
目标环境为 Ubuntu 26.04 / ROS 2 Lyrical；迁移目标是「先完整保全，再做适配」。

## 交付分层

1. **本仓库**：脱敏后的工程源码、模型、地图、配置和说明。配置中的敏感值已替换为占位符，
   不能直接当作实车配置使用。
2. **私有归档附件**（不在本仓库）：加密的原样备份，保留本机未提交内容、原始 Git 历史、
   工具链、构建结果与依赖。
3. **本地密钥**：解密备份用，必须通过独立的安全方式携带，绝不提交到 Git。丢失后无法解密。

## 脱敏做了什么

- Wi-Fi 口令与 SSID 替换为 `REDACTED_SECRET` / `REDACTED_WIFI_SSID`，并在文档、默认配置、
  用户路径与网络名中同步替换。占位符是**字面模板，不会自动读取环境变量**：实机请通过
  固件配网页或本地 ESP-IDF 配置提供。
- 通用令牌签名、URL 内嵌凭据、私钥头也会被扫描替换；解析器里的非密令牌、NVS 键名、
  UI 文案保持不变，避免误伤代码。
- 启发式扫描结论为「未发现残留的已知凭据字面量」，但这只是启发式结果，不等于保证。
  私有 IP、硬件标识、作者邮箱等按隐私策略另行评估（本项目已把本机用户目录统一替换为
  `/home/<user>`）。

## 恢复前先验证

下载全部附件到同一目录并核对 `SHA256SUMS`；如附件分片，按清单顺序合并后再校验。
解密到隔离目录检查，**不要直接覆盖目标系统的根目录或系统配置**：

```bash
set -o pipefail
mkdir -p "$HOME/ros-car-original"
openssl enc -d -aes-256-cbc -pbkdf2 -iter 200000 \
  -pass file:/安全位置/KEEP-LOCAL-backup.key \
  -in user-projects.tar.zst.enc \
  | zstd -d | tar -xpf - -C "$HOME/ros-car-original"
```

归档使用原路径去掉开头 `/` 的布局；旧工具链与 ROS 旧二进制仅用于保全与对照，
不保证在新系统直接运行。
