# LDC 复核问题修复记录

日期：2026-11-10。修复上一轮审查确认的三个问题。本批更新主机与网页代码；不修改车辆动力参数或自动应用标定候选。

## 已修复行为

1. **正常定位误停**：定位检查现按 odom 的 X、Y 分量和转角分别作严格大于比较，与本机 AMCL 1.5.2 的 `shouldUpdateFilter()` 保持一致。接收里程计和处理延迟定位时复用同一判断。`dx=dy=0.20m` 的斜向移动不会触发 0.25m 更新门限；真正超过任一分量后未更新，仍按原 1.5s 超时锁定导航。
2. **采集/回放并发**：两个入口共用启动互斥、停止代号和停止状态。停止会作废未完成的准备，服务退出时清理所有已登记任务；新的启动不能覆盖未结束任务的进程引用。
3. **复测版本关联**：创建复测使用当前显示的候选报告，页面同时展示报告版本、选中状态和将关联的版本。没有选择候选、只有故障摘要或报告属于另一会话时不能创建复测。新报告生成后也能重新选择旧报告。

AMCL 对照来源：[Nav2 1.5.2 官方源码](https://github.com/ros-navigation/navigation2/blob/1.5.2/nav2_amcl/src/amcl_node.cpp#L605)。本批未改变现有 AMCL 更新参数或重采样配置；以后调整这些配置仍应重新验证定位健康判定。

## 使用与生效

- 重启网页控制台后端并刷新网页，使已经加载到内存的桥接器和后端使用新代码。日常桌面启动入口保持原用法。
- 标定向导的第四步先选报告，核对“独立复测将关联报告”，再点“新建当前报告的独立复测”。
- 另一页面正在启动、运行或停止采集/回放时，新请求返回忙状态；待其结束再操作。
- 候选仍然是 `applied=false`，实车尺寸、里程计尺度和停车距离仍需独立测量。
